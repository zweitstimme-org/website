Forecast API

Öffentliche JSON-API für Wahlprognosen, Posterior-Draws und die Aktuelle Stimmung. Keine Authentifizierung. Nur GET. CORS: Access-Control-Allow-Origin: *.

Einzelumfragen liegen in der separaten Polling API. Diese Seite dokumentiert die Forecast API unter https://zweitstimme.org.

Discovery: /api/index.json · OpenAPI: /api/openapi.json

Forecast = Modelloutput für den Wahltag (Punktschätzung, Intervalle, Szenarien, Draws, Wahlkreise, Kandidateneinzug, Parlamentsgröße). Stimmung = geglättete tägliche Unterstützung, ohne Sitzszenarien. State-Forecasts nur im ~90-Tage-Fenster vor der Wahl.

Versionen: v1 ist die ältere Version und liefert nur Bundesprognosen. v2 ist aktuell und umfasst Bund, Länder und Stimmung. Für neue Integrationen v2 nutzen (/api/v2/federal/, /api/v2/state/, /api/v2/stimmung/).

Länder (v2): Neben der Zusammenfassung (/api/v2/state/{land}.json) und Draws (…/draws.json) gibt es Wahlkreise (…/districts.json), Kandidateneinzugschancen (…/candidates.json) und die Sitz-/Parlamentsgrößensimulation (…/parliament.json). Nach dem Wahltag liegen dieselben Pfade unter /api/v2/state/archive/{id}/….

Bund: Aktuelle Bundes-Wahlkreise unter /api/v2/federal/districts.json; archivierte Läufe unter /api/v2/federal/archive/{datum}/districts.json.

Stimmung: Die volle Zeitreihe (/api/v2/stimmung/federal.json) umfasst ca. 10 Jahre. Einzelner Tag: /api/v2/stimmung/federal/day/YYYY-MM-DD.json. Zeitraum: /month/YYYY-MM.json oder /year/YYYY.json. Heute: /current.json. Gleiche Pfade unter /api/v2/stimmung/state/{land}/.
